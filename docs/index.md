# corner2tag Documentation

corner2tag provides checkerboard calibration for event cameras, converters for supported event-data formats, and an optional Docker environment.

## Start Here

1. Review the [Prerequisites](prerequisite.md).
2. Convert your recording if it is not already in the required HDF5 format using [Data Conversion](data-conversion.md).
3. Follow the [Quick Start](quick-start.md) and [Checkerboard Calibration](checkerboard.md) guides.

To avoid installing the native C++ dependencies, use the [Docker](docker.md) workflow instead.
